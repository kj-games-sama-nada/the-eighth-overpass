# 第八歩道橋 — The Eighth Overpass

一人称の観察型ループホラーゲーム。夕暮れの歩道橋を渡り、日常への出口を探します。

## 遊び方

最初の橋は正常です。風景を覚えてください。

- 異変があれば、振り返って入口へ戻る。
- 異変がなければ、階段を下りた先まで進む。
- 8回続けて正しく判断すれば脱出。判断を間違えると0からやり直し。

「歩く」で移動、もう一度押すと停止。「振り返る」で180度向きを変えます。画面ドラッグや左右ボタンで見回せます。キーボードではWASD・矢印キー、Rで振り返り、Escで一時停止。

PC・スマートフォンのクリック／タップに対応。WebGL 2対応ブラウザが必要です。実機スマートフォンでの動作は未検証です。

## ローカルで遊ぶ

index.html をダウンロードしてMicrosoft EdgeまたはChromeで開くと、サーバーなしで遊べます。保存はブラウザと配信元ごとです。

## 作品について

人物・団体・場所はすべて架空です。橋と街の風景・人物・拡声器はコードで生成し、実在人物の写真や参考写真は収録していません。ゾンビ化・巨大化など10種類の異変を含みます。
